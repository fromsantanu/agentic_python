# Project 11
## Specialist Agents Collaboration

This project shows **how multiple expert agents work together** and **combine their opinions** before taking a final decision.

---

## Core idea (simple words)

Think of a **medical board meeting**:

* A **cardiologist** looks at heart risk
* A **general physician** looks at overall condition
* A **public health expert** looks at population risk
* A **coordinator** listens to everyone and gives the final decision

👉 No single expert decides alone
👉 Final decision is **combined and balanced**

That is exactly what we build here.

---

## What this system does

1. Same input is sent to **multiple specialist agents**
2. Each agent gives:

   * Opinion
   * Risk assessment
   * Recommendation
3. A **Coordinator Agent**:

   * Reads all opinions
   * Resolves conflicts
   * Produces final decision

This pattern is used in:

* Medical diagnosis boards
* Legal reviews
* Financial risk assessment
* Policy making

# 3. agents/schemas.py

*(Common data structures)*

```python
from pydantic import BaseModel
from typing import Literal, List

RiskLevel = Literal["LOW", "MODERATE", "HIGH", "CRITICAL"]

class CaseInput(BaseModel):
    age: int
    symptoms: List[str]
    duration_minutes: int
    known_conditions: List[str]

class SpecialistOpinion(BaseModel):
    specialist: str
    risk: RiskLevel
    reasoning: str
    recommendation: str

class FinalDecision(BaseModel):
    overall_risk: RiskLevel
    summary: str
    final_action: str
```

# 4. agents/llm.py

*(Shared LLM wrapper)*

```python
from openai import OpenAI

client = OpenAI()

def ask_llm(model: str, system_prompt: str, user_prompt: str) -> str:
    response = client.responses.create(
        model=model,
        instructions=system_prompt,
        input=user_prompt,
    )
    return response.output_text
```

# 5. agents/cardiology_agent.py

*(Heart specialist)*

```python
import json
from pydantic import ValidationError
from agents.schemas import CaseInput, SpecialistOpinion
from agents.llm import ask_llm

SYSTEM_PROMPT = """
You are a cardiology specialist.

Focus on:
- Chest pain
- Breathlessness
- Age-related heart risk

Give conservative medical opinion.

Return JSON only:
{
  "specialist": "Cardiology",
  "risk": "LOW|MODERATE|HIGH|CRITICAL",
  "reasoning": "...",
  "recommendation": "..."
}
"""

def evaluate(model: str, case: CaseInput) -> SpecialistOpinion:
    raw = ask_llm(model, SYSTEM_PROMPT, json.dumps(case.model_dump(), indent=2))
    try:
        return SpecialistOpinion.model_validate_json(raw)
    except ValidationError:
        raw2 = ask_llm(model, SYSTEM_PROMPT + "\nReturn JSON only.", json.dumps(case.model_dump(), indent=2))
        return SpecialistOpinion.model_validate_json(raw2)
```

# 8. agents/coordinator_agent.py

*(Combines opinions)*

```python
import json
from pydantic import ValidationError
from agents.schemas import SpecialistOpinion, FinalDecision
from agents.llm import ask_llm

SYSTEM_PROMPT = """
You are a senior coordinator.

You receive opinions from multiple specialists.
Your job:
- Resolve differences
- Choose safest overall risk
- Give final action

Rule:
- If any specialist says CRITICAL → overall CRITICAL
- Prefer safety over optimism

Return JSON only:
{
  "overall_risk": "...",
  "summary": "...",
  "final_action": "..."
}
"""

def decide(model: str, opinions: list[SpecialistOpinion]) -> FinalDecision:
    payload = [o.model_dump() for o in opinions]
    raw = ask_llm(model, SYSTEM_PROMPT, json.dumps(payload, indent=2))
    try:
        return FinalDecision.model_validate_json(raw)
    except ValidationError:
        raw2 = ask_llm(model, SYSTEM_PROMPT + "\nReturn JSON only.", json.dumps(payload, indent=2))
        return FinalDecision.model_validate_json(raw2)
```

# 9. app.py

*(Run collaboration)*

```python
import os
import json
from datetime import datetime
from dotenv import load_dotenv

from agents.schemas import CaseInput
from agents.cardiology_agent import evaluate as cardio_eval
from agents.general_agent import evaluate as general_eval
from agents.public_health_agent import evaluate as public_eval
from agents.coordinator_agent import decide

load_dotenv()

def env(name, default=""):
    return os.getenv(name, default)

def log(record: dict):
    os.makedirs("data", exist_ok=True)
    with open("data/collaboration_log.jsonl", "a") as f:
        f.write(json.dumps(record) + "\n")

def main():
    model = env("MODEL_NAME", "gpt-5.2")

    # Example case
    case = CaseInput(
        age=68,
        symptoms=["chest pain", "shortness of breath"],
        duration_minutes=40,
        known_conditions=["hypertension"]
    )

    print("\n=== CASE ===")
    print(case.model_dump())

    opinions = [
        cardio_eval(model, case),
        general_eval(model, case),
        public_eval(model, case),
    ]

    print("\n=== SPECIALIST OPINIONS ===")
    for o in opinions:
        print(o.specialist, o.risk, "-", o.recommendation)

    final = decide(model, opinions)

    print("\n=== FINAL DECISION ===")
    print("Overall Risk :", final.overall_risk)
    print("Summary      :", final.summary)
    print("Action       :", final.final_action)

    log({
        "time": datetime.now().isoformat(),
        "case": case.model_dump(),
        "opinions": [o.model_dump() for o in opinions],
        "final": final.model_dump()
    })

if __name__ == "__main__":
    main()
```
