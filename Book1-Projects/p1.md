# Project 1

## Daily Task Automation System (No Agent)

---

## 1. Problem Statement (Real-Life)

Every day, we do small repetitive tasks:

* Sending a daily reminder
* Printing a daily report
* Running a backup at a fixed time

Humans usually:

* Remember the task
* Check the time
* Do the same thing again and again

This is boring and error-prone.

---

## 2. What We Are Building

We are building a **simple automated system** that:

* Runs every day
* Checks the time
* Performs a fixed action automatically

👉 **Important:**
This system **does NOT think**
It only **follows instructions**

That’s why it is called a **workflow without an agent**.

---

## 3. How Humans Do This Today

Example: Daily reminder

1. Look at the clock
2. See it is 9:00 AM
3. Open laptop
4. Send reminder

If we forget → task is missed.

---

## 4. Workflow Design (Very Simple)

```
Time Trigger
     ↓
Check Rule
     ↓
Perform Action
```

Example:

```
Every day at 9 AM → Print reminder
```

No intelligence. No decision-making.

---

## 5. Python Code – Daily Reminder Automation

### Example 1: Simple Daily Reminder (Console Based)

```python
import time
from datetime import datetime

def daily_reminder():
    print("🔔 Reminder: Start your daily work!")

while True:
    now = datetime.now()
    current_time = now.strftime("%H:%M")

    # Run task at 09:00 AM
    if current_time == "09:00":
        daily_reminder()
        time.sleep(60)  # prevent repeating within same minute

    time.sleep(10)
```

### What is happening (Simple Words)

* The program keeps running
* Every 10 seconds it checks the time
* If time matches **09:00**
* It runs the task

Like an alarm clock ⏰

## 6. Python Code – Daily File Report Generator

### Example 2: Auto-Generate a Daily Report File

```python
from datetime import datetime

def generate_report():
    today = datetime.now().strftime("%Y-%m-%d")
    filename = f"report_{today}.txt"

    with open(filename, "w") as file:
        file.write("Daily Report\n")
        file.write("-----------------\n")
        file.write(f"Date: {today}\n")
        file.write("Status: Completed\n")

    print("📄 Daily report created:", filename)

generate_report()
```

### Real-Life Meaning

* Every day a new report file is created
* No human typing
* Same format, same steps

## 8. Common Mistakes

1. **Hard-coding wrong time**

   * `"9:00"` instead of `"09:00"`

2. **Forgetting sleep**

   * CPU usage becomes very high

3. **Expecting intelligence**

   * This system cannot decide or adjust
