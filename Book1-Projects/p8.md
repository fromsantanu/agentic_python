# Project 8 
## Intelligent Triage System

This project is **very close to real hospital, helpdesk, and emergency systems**.

---

## Core idea (simple words)

Think of a hospital OPD:

1. **Nurse at reception**

   * Collects patient details
   * Writes symptoms
   * Does basic checks

2. **Doctor**

   * Is called **only to decide priority**
   * Serious cases → immediate
   * Normal cases → wait

👉 That is exactly what we build here.

---

## What this system does

* **Workflow** handles intake (fast, rule-based)
* **Agent** decides priority (intelligent)
* Output is one of:

  * `CRITICAL`
  * `HIGH`
  * `NORMAL`
  * `LOW`

# 4. intake/validator.py

*(Rule-based safety checks)*

```python
def basic_validation(data: dict) -> dict:
    """
    Quick checks before AI.
    """
    missing = []

    required = ["age", "symptoms", "pain_level"]
    for r in required:
        if r not in data:
            missing.append(r)

    return {
        "ok": len(missing) == 0,
        "missing_fields": missing
    }
```

# 5. agent/schemas.py

*(Structured triage decision)*

```python
from pydantic import BaseModel
from typing import List, Literal

TriageLevel = Literal["CRITICAL", "HIGH", "NORMAL", "LOW"]

class TriageInput(BaseModel):
    patient_info: dict

class TriageDecision(BaseModel):
    level: TriageLevel
    reason: str
    immediate_action: str
    confidence: float
```

def ask_llm(model: str, system_prompt: str, user_prompt: str) -> str:
    response = client.responses.create(
        model=model,
        instructions=system_prompt,
        input=user_prompt,
    )
    return response.output_text

# 7. agent/triage_agent.py

*(The intelligence)*

```python
import json
from pydantic import ValidationError
from agent.schemas import TriageInput, TriageDecision
from agent.llm import ask_llm

SYSTEM_PROMPT = """
You are a medical triage assistant.

Your job:
- Assess patient severity
- Assign ONE triage level:
  CRITICAL, HIGH, NORMAL, LOW

Rules:
- Chest pain + breathing trouble → CRITICAL or HIGH
- Elderly patients need more caution
- Be conservative (safety first)

Return ONLY valid JSON in this format:
{
  "level": "...",
  "reason": "...",
  "immediate_action": "...",
  "confidence": 0.0-1.0
}
"""

def triage(model: str, data: TriageInput) -> TriageDecision:
    payload = json.dumps(data.model_dump(), indent=2)
    raw = ask_llm(model, SYSTEM_PROMPT, payload)

    try:
        return TriageDecision.model_validate_json(raw)
    except ValidationError:
        raw2 = ask_llm(model, SYSTEM_PROMPT + "\nReturn JSON only.", payload)
        return TriageDecision.model_validate_json(raw2)
```

# 8. workflow/router.py

*(Route based on priority)*

```python
def route_case(decision_level: str) -> str:
    if decision_level == "CRITICAL":
        return "Send to Emergency Room immediately"
    if decision_level == "HIGH":
        return "Doctor consultation within 10 minutes"
    if decision_level == "NORMAL":
        return "Wait in general queue"
    return "Self-care / schedule later visit"
```

# 9. app.py

*(Main orchestration)*

```python
import os
import json
from datetime import datetime
from dotenv import load_dotenv

from intake.form import collect_patient_input
from intake.validator import basic_validation
from agent.schemas import TriageInput
from agent.triage_agent import triage
from workflow.router import route_case

load_dotenv()

def env(name, default=""):
    return os.getenv(name, default)

def log_event(record: dict):
    os.makedirs("data", exist_ok=True)
    with open("data/triage_log.jsonl", "a") as f:
        f.write(json.dumps(record) + "\n")

def main():
    model = env("MODEL_NAME", "gpt-5.2")

    # Step 1: Intake
    patient_data = collect_patient_input()

    # Step 2: Validate
    validation = basic_validation(patient_data)
    if not validation["ok"]:
        print("❌ Intake incomplete:", validation)
        return

    # Step 3: AI triage
    triage_input = TriageInput(patient_info=patient_data)
    decision = triage(model, triage_input)

    # Step 4: Routing
    action = route_case(decision.level)

    # Output
    print("\n=== TRIAGE RESULT ===")
    print("Patient ID :", patient_data["patient_id"])
    print("Triage     :", decision.level)
    print("Reason     :", decision.reason)
    print("Action     :", action)
    print("Confidence :", decision.confidence)

    # Log
    log_event({
        "time": datetime.now().isoformat(),
        "patient_id": patient_data["patient_id"],
        "decision": decision.model_dump(),
        "route": action
    })

if __name__ == "__main__":
    main()
```
