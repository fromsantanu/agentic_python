## Memory-Aware Agent

This agent can **remember user preferences** (like “I prefer short reports”, “send alerts only in the morning”, “my city is Kalyani”, “I hate too many emails”) and then **change its behavior** in future runs.

We’ll use:

* OpenAI **Responses API** for the “thinking” part. ([OpenAI Platform][1])
* Environment variable `OPENAI_API_KEY` for safety (recommended). ([OpenAI Help Center][2])
* “Structured Outputs” concept (model returns reliable JSON). ([OpenAI Platform][3])

# agent/schemas.py

```python
from pydantic import BaseModel, Field
from typing import List, Literal, Optional, Dict, Any

class MemoryProfile(BaseModel):
    """
    Long-term preferences that should influence behavior.
    """
    preferred_location_name: Optional[str] = None
    latitude: Optional[float] = None
    longitude: Optional[float] = None
    timezone: Optional[str] = None

    report_style: Literal["SHORT", "DETAILED"] = "SHORT"
    email_enabled: bool = True
    max_emails_per_day: int = 1
    quiet_hours: List[str] = Field(default_factory=lambda: ["22:00-07:00"])  # local time
    preferred_send_time: Optional[str] = "09:00"  # local time

class MemoryUpdate(BaseModel):
    """
    What the memory agent extracted from new user messages.
    """
    updates: Dict[str, Any] = Field(default_factory=dict)
    reason: str = ""

class GoalInput(BaseModel):
    user_message: str
    goal: str

DecisionType = Literal["DO_NOW", "SCHEDULE", "SKIP_EMAIL", "ASK_USER"]

class Decision(BaseModel):
    decision: DecisionType
    reason: str
    next_step: str
    plan_steps: List[str] = Field(default_factory=list)
    suggested_time: Optional[str] = None
    confidence: float = Field(ge=0, le=1, default=0.7)
```

# agent/memory_store.py

```python
import json
import os
from typing import Dict, Any
from agent.schemas import MemoryProfile

def ensure_parent(path: str) -> None:
    parent = os.path.dirname(path)
    if parent:
        os.makedirs(parent, exist_ok=True)

def load_memory(path: str) -> MemoryProfile:
    if not os.path.exists(path):
        return MemoryProfile()
    with open(path, "r", encoding="utf-8") as f:
        data = json.load(f)
    return MemoryProfile(**data)

def save_memory(path: str, mem: MemoryProfile) -> None:
    ensure_parent(path)
    with open(path, "w", encoding="utf-8") as f:
        json.dump(mem.model_dump(), f, indent=2, ensure_ascii=False)

def merge_updates(mem: MemoryProfile, updates: Dict[str, Any]) -> MemoryProfile:
    """
    Apply partial updates safely.
    """
    data = mem.model_dump()
    for k, v in updates.items():
        if k in data:
            data[k] = v
    return MemoryProfile(**data)
```

# agent/memory_agent.py  (extract preferences from user text)

This is the “memory-aware” part.

Example user message:

* “Please keep reports detailed and don’t email at night.”

Agent extracts:

* report_style=DETAILED
* quiet_hours include night time
* maybe email_enabled remains true but scheduled

```python
import json
from pydantic import ValidationError
from agent.schemas import MemoryProfile, MemoryUpdate
from agent.llm import ask

MEMORY_INSTRUCTIONS = """
You are a memory extraction agent.

Given:
- The user's new message
- The current memory profile

Task:
- Extract durable preferences only (things likely to remain true).
- Return ONLY JSON in this schema:

{
  "updates": { "field": value, ... },
  "reason": "short reason"
}

Allowed fields you can update:
preferred_location_name, latitude, longitude, timezone,
report_style, email_enabled, max_emails_per_day,
quiet_hours, preferred_send_time

Rules:
- Do NOT invent data.
- If nothing to update, return {"updates": {}, "reason": "..."}.
"""

def extract_memory_updates(model_name: str, user_message: str, current_memory: MemoryProfile) -> MemoryUpdate:
    payload = {
        "user_message": user_message,
        "current_memory": current_memory.model_dump(),
    }
    raw = ask(model_name, MEMORY_INSTRUCTIONS, json.dumps(payload, indent=2))

    try:
        return MemoryUpdate.model_validate_json(raw)
    except ValidationError:
        # simple repair retry
        raw2 = ask(model_name, MEMORY_INSTRUCTIONS + "\nReturn VALID JSON only.", json.dumps(payload, indent=2))
        return MemoryUpdate.model_validate_json(raw2)
```

# agent/decision_agent.py  (use memory to decide what to do)

```python
import json
from pydantic import ValidationError
from agent.schemas import Decision, MemoryProfile
from agent.llm import ask

DECISION_INSTRUCTIONS = """
You are a decision-making agent.

You must use the user's memory profile to decide what to do.

Decisions:
- DO_NOW: do it immediately
- SCHEDULE: choose a time (respect quiet_hours and preferred_send_time)
- SKIP_EMAIL: do report but do not email (if user hates emails or max limit reached)
- ASK_USER: if info is missing

Return ONLY JSON in this schema:
{
  "decision": "DO_NOW|SCHEDULE|SKIP_EMAIL|ASK_USER",
  "reason": "...",
  "next_step": "...",
  "plan_steps": ["..."],
  "suggested_time": "optional",
  "confidence": 0.0-1.0
}

Rules:
- Keep it practical.
- Respect quiet_hours.
- Prefer SHORT or DETAILED report style based on memory.
"""

def decide(model_name: str, goal: str, memory: MemoryProfile, runtime_context: dict) -> Decision:
    payload = {
        "goal": goal,
        "memory": memory.model_dump(),
        "runtime_context": runtime_context
    }
    raw = ask(model_name, DECISION_INSTRUCTIONS, json.dumps(payload, indent=2))
    try:
        return Decision.model_validate_json(raw)
    except ValidationError:
        raw2 = ask(model_name, DECISION_INSTRUCTIONS + "\nReturn VALID JSON only.", json.dumps(payload, indent=2))
        return Decision.model_validate_json(raw2)
```

# tools/registry.py

```python
from typing import Callable, Dict, Any

ToolFn = Callable[[Dict[str, Any]], Dict[str, Any]]

class ToolRegistry:
    def __init__(self) -> None:
        self.tools: Dict[str, ToolFn] = {}

    def register(self, name: str, fn: ToolFn) -> None:
        self.tools[name] = fn

    def run(self, name: str, args: Dict[str, Any]) -> Dict[str, Any]:
        if name not in self.tools:
            return {"ok": False, "error": f"Unknown tool: {name}"}
        try:
            return self.tools[name](args)
        except Exception as e:
            return {"ok": False, "error": str(e)}
```

```python
import requests
from typing import Dict, Any

def fetch_weather(args: Dict[str, Any]) -> Dict[str, Any]:
    lat = float(args["latitude"])
    lon = float(args["longitude"])
    tz = str(args.get("timezone", "UTC"))

    url = (
        "https://api.open-meteo.com/v1/forecast"
        f"?latitude={lat}&longitude={lon}"
        "&current=temperature_2m,relative_humidity_2m,wind_speed_10m,precipitation"
        f"&timezone={tz}"
    )

    r = requests.get(url, timeout=20)
    r.raise_for_status()
    data = r.json()
    cur = data.get("current", {})

    return {
        "ok": True,
        "observed_at": str(cur.get("time")),
        "temperature_c": float(cur.get("temperature_2m", 0.0)),
        "humidity_percent": float(cur.get("relative_humidity_2m", 0.0)),
        "wind_kph": float(cur.get("wind_speed_10m", 0.0)),
        "rain_mm": float(cur.get("precipitation", 0.0)),
```

# tools/reporting.py  (write_weather_report)

Memory affects: SHORT vs DETAILED.

```python
import os
from datetime import datetime
from typing import Dict, Any

def write_weather_report(args: Dict[str, Any]) -> Dict[str, Any]:
    reports_dir = args["reports_dir"]
    location_name = args.get("location_name", "Unknown")
    style = args.get("style", "SHORT")  # SHORT or DETAILED
    weather = args["weather"]

    os.makedirs(reports_dir, exist_ok=True)
    day = datetime.now().strftime("%Y-%m-%d")
    filename = os.path.join(reports_dir, f"weather_report_{day}.md")

    lines = []
    lines.append("# Daily Weather Report\n")
    lines.append(f"- **Date:** {day}")
    lines.append(f"- **Location:** {location_name}\n")

    lines.append("## Current Reading\n")
    lines.append(f"- **Observed at:** {weather.get('observed_at')}")
    lines.append(f"- **Temperature:** {weather.get('temperature_c')} °C")
    lines.append(f"- **Humidity:** {weather.get('humidity_percent')} %")
    lines.append(f"- **Wind:** {weather.get('wind_kph')} km/h")
    lines.append(f"- **Rain:** {weather.get('rain_mm')} mm\n")

    if style == "DETAILED":
        # add simple rule-based notes (still not AI)
        notes = []
        if weather.get("temperature_c", 0) >= 35:
            notes.append("🔥 Hot weather: drink water, avoid afternoon sun.")
        if weather.get("rain_mm", 0) >= 5:
            notes.append("🌧️ Rain expected: carry umbrella, drive carefully.")
        if weather.get("wind_kph", 0) >= 35:
            notes.append("💨 Strong winds: be cautious outdoors.")

        lines.append("## Notes\n")
        if notes:
            for n in notes:
                lines.append(f"- {n}")
        else:
            lines.append("- No special conditions detected.\n")

    with open(filename, "w", encoding="utf-8") as f:
        f.write("\n".join(lines))

    return {"ok": True, "report_file": filename}
```

```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from typing import Dict, Any

def send_email(args: Dict[str, Any]) -> Dict[str, Any]:
    smtp_host = args["smtp_host"]
    smtp_port = int(args["smtp_port"])
    username = args["smtp_username"]
    password = args["smtp_password"]
    to_email = args["to_email"]

    subject = args["subject"]
    body_text = args["body_text"]

    msg = MIMEMultipart()
    msg["From"] = username
    msg["To"] = to_email
    msg["Subject"] = subject
    msg.attach(MIMEText(body_text, "plain", "utf-8"))

    with smtplib.SMTP(smtp_host, smtp_port) as server:
        server.starttls()
        server.login(username, password)
        server.send_message(msg)

    return {"ok": True}
```

# app.py (main workflow)

This shows the full loop:

1. Load memory
2. Read a “user message” (you can change it)
3. Update memory if needed
4. Use memory to decide
5. Execute tools
6. Save memory + log

```python
import os
import json
from datetime import datetime

from dotenv import load_dotenv
from agent.schemas import MemoryProfile
from agent.memory_store import load_memory, save_memory, merge_updates
from agent.memory_agent import extract_memory_updates
from agent.decision_agent import decide
from tools import build_registry

load_dotenv()

def env(name: str, default: str = "") -> str:
    return os.getenv(name, default).strip()

def append_run_log(path: str, item: dict) -> None:
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(item, ensure_ascii=False) + "\n")

def in_quiet_hours(local_hhmm: str, quiet_ranges: list[str]) -> bool:
    """
    Very simple checker:
    quiet_hours like ["22:00-07:00"]
    """
    def to_minutes(hhmm: str) -> int:
        h, m = hhmm.split(":")
        return int(h) * 60 + int(m)

    now = to_minutes(local_hhmm)

    for r in quiet_ranges:
        start, end = r.split("-")
        s = to_minutes(start)
        e = to_minutes(end)
        if s <= e:
            if s <= now <= e:
                return True
        else:
            # wraps midnight (e.g., 22:00-07:00)
            if now >= s or now <= e:
                return True
    return False

def main():
    model_name = env("MODEL_NAME", "gpt-5.2")
    memory_path = env("MEMORY_PATH", "data/memory.json")
    run_log_path = env("RUN_LOG_PATH", "data/run_log.jsonl")

    # Defaults (if memory has no location yet)
    defaults = {
        "latitude": float(env("LATITUDE", "0")),
        "longitude": float(env("LONGITUDE", "0")),
        "timezone": env("TIMEZONE", "UTC"),
        "location_name": env("LOCATION_NAME", "Unknown"),
        "reports_dir": env("REPORTS_DIR", "reports"),
        "smtp_host": env("SMTP_HOST", ""),
        "smtp_port": int(env("SMTP_PORT", "587") or "587"),
        "smtp_username": env("SMTP_USERNAME", ""),
        "smtp_password": env("SMTP_PASSWORD", ""),
        "to_email": env("ALERT_TO_EMAIL", ""),
    }

    registry = build_registry()

    # 1) Load memory
    memory = load_memory(memory_path)

    # 2) Simulated user message (for your demo / book)
    # Change this line to test memory learning:
    user_message = "From now on, I want detailed reports. Also, don't email me at night."
    goal = "Create today's weather report and email it to me."

    # 3) Memory update step
    upd = extract_memory_updates(model_name, user_message, memory)
    if upd.updates:
        memory = merge_updates(memory, upd.updates)
        save_memory(memory_path, memory)

    # 4) Build runtime context
    # In a real app, we'd know current local time. For book simplicity:
    local_time = datetime.now().strftime("%H:%M")
    runtime_context = {
        "local_time_hhmm": local_time,
        "emails_sent_today": 0,  # you can persist this too, later
    }

    # 5) Decide using memory
    decision = decide(model_name, goal, memory, runtime_context)

    # 6) Execute (tool-based workflow)
    # Always fetch weather + write report. Email depends on decision and memory.
    lat = memory.latitude if memory.latitude is not None else defaults["latitude"]
    lon = memory.longitude if memory.longitude is not None else defaults["longitude"]
    tz = memory.timezone if memory.timezone is not None else defaults["timezone"]
    loc_name = memory.preferred_location_name or defaults["location_name"]

    weather = registry.run("fetch_weather", {"latitude": lat, "longitude": lon, "timezone": tz})
    if not weather.get("ok"):
        print("❌ Weather fetch failed:", weather)
        return

    report = registry.run("write_weather_report", {
        "reports_dir": defaults["reports_dir"],
        "location_name": loc_name,
        "style": memory.report_style,
        "weather": weather
    })

    if not report.get("ok"):
        print("❌ Report generation failed:", report)
        return

    email_attempted = False
    email_sent = False

    # Decide if email should be sent now
    quiet = in_quiet_hours(local_time, memory.quiet_hours)

    if decision.decision in ("SKIP_EMAIL", "ASK_USER"):
        pass
    elif not memory.email_enabled:
        pass
    elif quiet:
        # If quiet hours, do not email now
        pass
    else:
        # send email
        email_attempted = True
        body = f"Report created: {report['report_file']}\n\nLatest Weather:\n{json.dumps(weather, indent=2)}"
        res = registry.run("send_email", {
            "smtp_host": defaults["smtp_host"],
            "smtp_port": defaults["smtp_port"],
            "smtp_username": defaults["smtp_username"],
            "smtp_password": defaults["smtp_password"],
            "to_email": defaults["to_email"],
            "subject": f"Daily Weather Report ({loc_name})",
            "body_text": body
        })
        email_sent = bool(res.get("ok"))

    # 7) Print summary
    print("\n=== MEMORY-AWARE AGENT ===")
    print("User message:", user_message)
    print("Memory updates:", upd.updates)
    print("Current memory:", memory.model_dump())
    print("\nDecision:", decision.model_dump())
    print("\nReport file:", report.get("report_file"))
    print("Email attempted:", email_attempted, "Email sent:", email_sent)

    # 8) Log run
    append_run_log(run_log_path, {
        "ts": datetime.now().isoformat(timespec="seconds"),
        "user_message": user_message,
        "memory_updates": upd.updates,
        "decision": decision.model_dump(),
        "report_file": report.get("report_file"),
        "email_attempted": email_attempted,
        "email_sent": email_sent
    })

if __name__ == "__main__":
    main()
```

## What makes it “Memory-Aware” (simple words)

A normal agent is like a helpful person with no past:

> “Tell me again what you like.”

A memory-aware agent is like a helpful assistant who remembers:

> “Last time you told me you hate emails at night, so I won’t disturb you.”

That’s the big difference.

---

## Common mistakes

* Forgetting `OPENAI_API_KEY` in `.env` ([OpenAI Help Center][2])
* Expecting memory to update without a clear user message
* Storing too many things in memory (store only stable preferences)
* Email failing because Gmail needs an **App Password**
